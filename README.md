# 中日翻訳アプリ（Chinese-Japanese Translator）

このアプリは、簡単に中国語を日本語に翻訳できるWebアプリです。FlaskというPythonのWebフレームワークと、Google翻訳APIを使って開発しました。

## 使用方法
1. テキストボックスに中国語を入力します。
2. 「翻訳」ボタンを押すと、日本語に翻訳された結果が表示されます。

## 開発環境
- 言語: Python
- フレームワーク: Flask
- API: Google翻訳API
- エディタ: Visual Studio Code

## 対応プラットフォーム
- Webブラウザ（PC・スマホ）

## 注意点
- Google翻訳APIを使っているので、インターネット接続が必要です。
- 翻訳結果は参考程度にしてください。
